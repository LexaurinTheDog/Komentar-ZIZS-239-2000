# Komentář k zákonu č. 239/2000 Sb., o integrovaném záchranném systému a o změně některých zákonů

Otevřený komentář k zákonu o integrovaném záchranném systému — § po §: doslovné znění, výklad, kazuistika, protiargumenty a praktický závěr; složky IZS a jejich koordinace, úkoly ministerstev, krajů a obcí, ochrana obyvatelstva, velitel zásahu, osobní a věcná pomoc, povinnosti osob při mimořádných událostech, přestupky a náhrady.

Konsolidované znění: dokument e-Sbírky `SB-2000-00239_2025-08-19`.
